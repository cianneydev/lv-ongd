# 🌿 ONG Lamentation Végétale (LV/ONGD)

> **Éveiller • Former • Agir**

Bienvenue sur le dépôt officiel du site web de l'**ONG Lamentation Végétale (LV/ONGD)**. 
Cette organisation non gouvernementale de développement œuvre pour la protection de l'environnement, la conservation de la biodiversité et la lutte contre le changement climatique à Lubumbashi, en République Démocratique du Congo (RDC).

## 🎯 Notre Mission

*   **Sensibiliser** : Éveiller les consciences sur les enjeux environnementaux.
*   **Former** : Transmettre les connaissances et les compétences nécessaires.
*   **Agir** : Mener des actions concrètes sur le terrain (reboisement, gestion des déchets, etc.).

---

## 🛠️ Technologies Utilisées

Ce site est un projet **100% statique**, léger et rapide, conçu avec :
*   **HTML5** : Structure des pages.
*   **CSS3** : Design, mise en page et responsive (mobile/tablette/PC).
*   **JavaScript** : Interactivité (Menu hamburger).
*   **GitHub Pages / Vercel** : Hébergement et déploiement continu.
*   **Typeform** : Formulaire de contact intégré.
